Frequently Asked Questions

Answers to the most common questions about air ambulance services in Delhi.

How fast can REACT reach Delhi?

REACT maintains an 18-minute response time in Delhi. With round-the-clock standby crews and pre-positioned aircraft at Delhi's airports, we can mobilise rapidly for any critical medical emergency across the NCR.

Which airports does REACT use in Delhi?

REACT operates through Indira Gandhi International Airport (DEL) for long-range missions and Safdarjung Airport for shorter-haul and helicopter operations, minimising transit time between hospital and aircraft.

Which hospitals does REACT serve in Delhi?

REACT coordinates with AIIMS, Fortis Escorts Heart Institute, Max Super Speciality Hospital, Medanta The Medicity, and other leading tertiary care centres across Delhi and NCR for seamless bed-to-bed transfers.

Does REACT provide international repatriation from Delhi?

Yes. Delhi's IGI Airport is a primary international gateway. REACT handles all medical, logistical, and documentation requirements for international transfers, including visa coordination and destination hospital liaison.
