Technical Overview

Technical Specifications

For your reference — what the website is built on and what you will need to maintain it.

What It's Built With

  • Pure HTML, CSS, JavaScript — no framework
  • Single file (index.html) — easy to host anywhere
  • Three.js — particle/animation effects
  • GSAP 3 — scroll animations and transitions
  • Google Fonts (Bebas Neue, Space Mono, Barlow)
  • No backend required for the static site

Hosting Requirements

  • Any standard web hosting works (no special server)
  • Recommended: Vercel, Netlify, or cPanel hosting
  • SSL certificate (HTTPS) — required for trust
  • Minimum bandwidth: 5 GB/month
  • Domain: nlcurantis.in or niams.in
  • Email for contact form: ops@nlcurantis.in

Contact Form Backend

  • Form submissions need a backend service to receive emails
  • Options: Formspree (free), EmailJS, or custom SMTP
  • All inquiries sent to: ops@nlcurantis.in
  • WhatsApp integration is already configured
  • Setup time: ~1 hour once form service is chosen

Mobile & Browser Support

  • Fully responsive — tested down to 320px width
  • Mobile hamburger menu on screens ≤920px
  • Heavy animations disabled on mobile for performance
  • Supports: Chrome, Safari, Firefox, Edge (latest 2 versions)
  • iOS Safari and Android Chrome fully supported

Content You Own & Can Update

After launch, the following items can be updated by sharing them with your developer — no technical knowledge required from your side:

  • Hero photos (swap any of the 3 carousel images)
  • Stats numbers (missions, response time, cities, success rate)
  • Testimonial quotes, names, and cities
  • Partner/hospital logos (add or remove)
  • FAQ questions and answers (add, edit, or remove)
  • Fleet specifications (aircraft models, range, capacity)
  • Contact details (phone numbers, email, WhatsApp)
  • Team member photos and profiles (if added in Phase 2)
